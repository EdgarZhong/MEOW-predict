### 收官：特征侧统一根因 + 宽进严出修正（2026-05-27）

- **统一根因（三族都死在"基线已含该族主体"）**：OFI / 成交冲击 / 动量-反转三族单族追加全走弱，根因同一——每族最可外推的主体基线 R02 已含：OFI 与成交冲击在 `norm_core` 的 cross-z（`ofi_*_cs_z` / `trade_pressure_*_cs_z`）；**动量/反转在 `legacy` 的 `lagret12`**（`LEGACY_COLS`，feature_registry.py:293，12 步滞后收益、和预测目标 `fret12` 同窗口，是动量/反转信号主体）。所以"动量为何也不行"= 主体不是 P3 才加、从一开始就在基线生效（Ridge 自学符号：正=动量、负=反转）；P3 测的只是其上的多窗口+变体+交互**边际**。线性吃不进交互（Q3 证），唯一榨出的是 C2 交互（"动量只在某种微结构状态下有效"这个条件化信息基线没显式建过）。
- **宽进严出口径修正**：+0.003 地板只管"采不采纳"、不管"要不要进 expanding 验证"（AGENTS §4.4/§4.6）。据此发现 C2/O4 单独此前被地板误挡、从没跑过 expanding（数据真空），补跑 runs `20260527_c2_gate_v1` / `20260527_o4_gate_v1`（线性 Ridge 上，作线性章节收尾 + 确认 X1 靶子成色；对 P4 树无直接指导）。
- **C2/O4 单独 expanding 补跑结果（2026-05-27，宽进严出补齐数据真空）**：两者 expanding 表现一致——都干净、小、单独低于地板，**不是噪声/有害，是"小而真、低于采纳地板"**：
  - **C2（R02 + cond_mom 交互）**：Δcorr **+0.00275**（corr_mean 0.06514 vs 基线 0.06239）；corr_min 0.03638↑（基线 0.03348）、stability 0.04965↑、12 折全正、daily IC mean 0.04159↑ / IC-IR 1.145↑（基线 1.025）、gap 0.00636（略增但小）。
  - **O4（R02 + ofi_safe）**：Δcorr **+0.00219**（corr_mean 0.06458）；corr_min 0.03942↑（升更多）、stability 0.05005↑、12 折全正、daily IC mean 0.04079↑ / IC-IR 1.127↑、gap 0.00566（反比基线 0.00574 略好、无过拟合）。
  - **洞察（回答"X1 是真互补还是重叠"）**：C2 单 +0.00275 + O4 单 +0.00219 = **+0.00494**，X1 实测 expanding Δ **+0.0044** < 之和 → **近似可加、仅轻微重叠**。说明 X1 的分不是单条腿撑的，ofi_safe 与 cond_mom 交互各自独立都抬 expanding/选股 IC/最坏折——**X1 靶子扎实**。线性章节"数据真空"补齐、正式收官。两者 make_decision=reject（卡 +0.003 地板），但按宽进严出此为"采纳"判定、非"该不该验证"——它们干净、跨视角一致，只是单独不足以采纳，叠成 X1 才破地板。
- **战略结论（转 P4）**：线性特征侧已到头（三族主体被基线吃 + 线性吃不进交互），冲高分主战场转 P4 树。线性阶段定位 = **立地基**（评测体系 / 数据认知 / 提交通道 / 9 stage 特征工程，全可复用）**而非求最优**；特征价值依赖模型，树阶段应**喂大集让树重评、不重搜组合**（手工交互对树冗余、cross-z 对树要留）。
